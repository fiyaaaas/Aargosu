# Aargosu — Aarka Hanad for Android by FIYAAS



**Aarka Hanad** waa ciyaar Android ah oo Af-Soomaali ku qoran, kana mid ah mashaariicda **FIYAAS**. Kaydkan hadda waxa uu bixiyaa APK la rakibi karo; source code-ka iyo habka dib loogu dhisayo app-ka kuma jiraan.



**Aarka Hanad** is a Somali-language Android game in the **FIYAAS** portfolio. This repository currently provides the compiled APK, not the app source code or build instructions.



## Waxa ku jira / What it includes

Khibrad moobil oo shaashad-buuxda ah, jihada jiifka (landscape), iyo tilmaamo Af-Soomaali ah. Qalabka keyboard-ka ee qalabka taageera: **Arrow keys / WASD** si loo dhaqaaqo, **Shift** = “ORO,” **Space / E** = “FICIL,” iyo **Esc** = joojin. Magaca gudaha APK-ga waa **Aarka Hanad**; Android package ID: `com.fiyaas.aarkahanad`.



## Soo dejin iyo rakibid / Download and install

Soo dejiso [`AARGOSI.apk`](./AARGOSI.apk). Android-ku waxa uu ku weydiin karaa oggolaansho rakibidda app laga soo dejiyey meel ka baxsan Play Store. Ku rakib APK kaliya haddii aad ku kalsoon tahay meesha aad ka heshay.
