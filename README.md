# Aargosu — Aarka Hanad Android Game by FIYAAS



**Aarka Hanad** is a Somali-language Android game in the **FIYAAS** portfolio. This repository currently provides the compiled APK; the app source code and build instructions are not included.



## Game Details

The APK contains a full-screen mobile experience in landscape orientation with Somali-language instructions. On devices that support a keyboard, use **Arrow keys or WASD** to move, **Shift** for “ORO,” **Space or E** for “FICIL,” and **Esc** to pause. The Android package ID is `com.fiyaas.aarkahanad`.



## Download and Install

Download [`AARGOSI.apk`](./AARGOSI.apk). Android may ask you to allow installation from outside the Play Store. Only install APK files from a source you trust.
